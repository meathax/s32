# Verilator cross-validation harness

Independent (Verilator 5.x) checks that complement the ModelSim regression.
Verilator is a second, structurally different simulator — agreement across both
raises confidence; disagreement is a live lead.

Requires the machine-wide `verilator-safe` and `verilator-sim-safe` launchers
on PATH. They use the native UCRT64 toolchain under
`D:\vibes\fpga\toolchains\msys64`, force `--threads 1`, and allocate every
generated model beneath a unique `R:\Verilator` workspace. Run from the repo
root; never invoke a raw Verilator binary or reuse a local `obj_dir`.

## tb_sdram_edge.sv — SDRAM arbitration / request-latch fix

Closes a coverage gap in the ModelSim suite: every ModelSim TB models `clk_sys`
rising **half a `clk_ram` period offset** from `clk_ram`, but the real MiSTer PLL
emits `clk_sys` **edge-aligned** with `clk_ram`. The ga2/arabfgt black-screen
root cause (`rtl/mem/sdram.sv` dropping a request whose rising edge collides with
the clearing ack/pend — the V60 icache-fill chain) was only ever simulated in
the half-offset phase.

The testbench:
* deliberately retains the historical four-exact-word V60 fill pattern as an
  adversarial edge-latch regression (single-cycle `p0_req` pulses, word N+1
  chained off word N's ack); production's one-request aligned line burst is
  covered by `verif/common/tb_sdram_p0_throughput.sv`;
* runs concurrent p5 (V25) bursts to perturb arbitration parity;
* selects the clock coupling: **edge-aligned** (default, = hardware) or
  **half-offset** (`+define+HALF_OFFSET`, = the ModelSim TBs);
* sweeps the p5 parity phase via `+p5delay=N`;
* hard-fails on any hung transaction (request-drop signature).

### Run

```bash
bash verif/verilator/run_sdram_edge.sh      # 2x2 {fixed,prefix} x {edge,half}
bash verif/verilator/sweep_sdram_edge.sh    # + p5 parity sweep d0..d15
```

`scratch/sdram_prefix.sv` (regenerated by `scratch/make_sdram_prefix.py`) is a
pre-fix reconstruction of the request-drop bug, used to prove the test has teeth.

### Result (2026-07-22)

| DUT | edge-aligned | half-offset |
|-----|--------------|-------------|
| **fixed** `rtl/mem/sdram.sv` | PASS (all 16 parities) | PASS (all 16 parities) |
| **pre-fix** reconstruction   | pass\* | **HANG** (all 16 parities) |

The fix passes both phases, all parities (32/32). The pre-fix hangs on the
first icache fill in the half-offset phase — the exact signature the full-core
ModelSim sim (`tb_core_v25sdram`) found. \*The unit stimulus does not reproduce
the pre-fix drop in the edge-aligned phase; the hardware edge-aligned fault
depends on full-core arbitration history (CE cadence, real request spacing) that
a clean unit stimulus does not recreate. This harness validates that the fix is
**safe** in the edge-aligned hardware phase and has proven teeth in half-offset.
